Formal Grammars, Chomsky Hierarchy & Semi-Thue Rewriting Systems

Formal grammars provide mathematical frameworks for describing syntax and language generation. Semi-Thue systems formalize string rewriting operations that model non-deterministic computational processes.

1. The Chomsky Hierarchy (Language Inclusion: L3 ⊂ L2 ⊂ L1 ⊂ L0)

Introduced by Noam Chomsky in 1956, formal grammars are classified into four tiers based on production rule constraints:

Tier Grammar Type Production Rule Form Recognizing Automaton Parsing Complexity Word Problem
Type-3 Regular A → wB or A → w (Right-Linear)
A → Bw or A → w (Left-Linear)		 Finite State Automaton (DFA / NFA) Linear: O(n) Decidable
Type-2 Context-Free (CFG) A → γ where A ∈ VN, γ ∈ (VN ∪ Σ)* Pushdown Automaton (PDA) Polynomial: O(n³) (CYK/Earley) Decidable
Type-1 Context-Sensitive (CSG) α → β with |α| ≤ |β| (Non-contracting) Linear Bounded Automaton (LBA) PSPACE-complete Decidable
Type-0 Unrestricted / Semi-Thue α → β (Arbitrary rewriting, α ≠ ε) Turing Machine Undecidable Recursively Enumerable

2. Detailed Tier Specifications & Interactive Presets

Type-3: Regular Grammars

Regular grammars produce languages recognized by finite state automata. Non-terminals can appear only at the extreme right (Right-Linear) or extreme left (Left-Linear) of the production rule.

Example: Alternating tokens (ab)+:

S → aA, A → bS, A → b

Type-2: Context-Free Grammars (CFG)

Every rule has a single isolated non-terminal on the LHS (|LHS| = 1). Substitutions are independent of surrounding context.

Example 1: Balanced counting { aⁿbⁿ | n ≥ 0 }:

S → aSb | ε

Example 2: Dyck Language (Balanced Parentheses):

S → (S)S | ε

Type-1: Context-Sensitive Grammars (CSG)

Rules are non-contracting: the length of the replacement must be greater than or equal to the source (|α| ≤ |β|). Strings never shrink during derivation, which makes the word recognition problem decidable in PSPACE.

Example: Three-way balanced language { aⁿbⁿcⁿ | n ≥ 1 }:

S → aSBC | aBC, CB → BC, aB → ab, bB → bb, bC → bc, cC → cc

Type-0: Semi-Thue Systems & Unrestricted Grammars

Introduced by Axel Thue in 1914, Semi-Thue systems consist of an alphabet and directed substitution rules u → v. Type-0 systems are computationally Turing-complete.

Example: Ripple-Carry Binary Incrementer (>1011+ → 1100):

0+ → 1, 1+ → +0, >+ → >1, > → ε

3. Algorithm & Search Theory

Breadth-First Search (BFS) vs. Depth-First Search (DFS)

  • Why BFS is required: BFS explores states level by level. Because each step corresponds to one rule replacement, BFS is guaranteed to find the shortest derivation path in terms of steps.
  • Why DFS fails: Rewriting systems often contain infinite branch cycles (e.g. S → aSb or A → B, B → A). DFS can descend infinitely down an unproductive branch, missing a valid derivation.

The Halting Problem & Safety Limits

The Word Problem for general Type-0 grammars is undecidable (equivalent to the Halting Problem). Rules can expand and contract strings arbitrarily. Therefore, practical visualizers must enforce Max Search Depth and Max Visited Nodes safety limits to guarantee termination.

Monotonic Length Pruning

When all rules satisfy |LHS| ≤ |RHS|, derived string lengths never decrease. If a state's length exceeds the target string length, that branch can never reach the target and is safely pruned, significantly reducing search space without compromising completeness.
